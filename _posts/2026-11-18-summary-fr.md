### [Java4Shell : exécution de code à distance dans OpenJDK via Base64](https://calif.io/java4shell/) ⭐️ 8.0/10

Le chercheur Calif décrit une vulnérabilité d&\#x27;exécution de code à distance dans OpenJDK, déclenchée lors du traitement de données en Base64. Le write-up présente une technique de heap grooming réalisable par le réseau \(« Remote Heap Feng Shui »\), dont la fiabilité dépend des conditions réseau, comme le temps aller-retour et la gigue ; selon un commentaire, l&\#x27;attaque a été testée sur Internet via des adresses IP publiques. Le contenu complet de l&\#x27;article n&\#x27;était pas disponible pour cette analyse, donc les versions touchées et les détails d&\#x27;exploitation restent à vérifier auprès de la source primaire.

hackernews · werrett · Nov 17, 21:11 · [Discussion](https://news.ycombinator.com/item?id=50538240)

**「Contexte」** La faille concerne la routine d&\#x27;assembleur optimisée de OpenJDK qui gère le décodage Base64 avec les instructions AVX-512, un composant de performance plutôt qu&\#x27;une simple couche applicative. Selon les analyses publiées, la corruption de mémoire tas qui en résulte peut provoquer le plantage de la JVM, exposer des données sensibles conservées en mémoire ou, dans certaines conditions, permettre une exécution de code à distance.

**「Impact pour les équipes」** Les équipes qui exploitent des JDK basés sur HotSpot \(OpenJDK, Oracle JDK ou GraalVM JDK\) doivent évaluer leur exposition, en s&\#x27;appuyant par exemple sur les scripts de détection publiés par Semgrep, dont les conditions sont décrites dans les commentaires. Ces scripts n&\#x27;ont pas été examinés dans le cadre de cette analyse.

**「Discussion communautaire」** Un commentateur affirme, sans confirmation, que la vulnérabilité serait liée à l&\#x27;implémentation AVX512 du décodage Base64 et qu&\#x27;un contournement consisterait à lancer Java avec -XX:UseAVX=2. Un autre commentateur, rattaché à Semgrep, juge les conditions d&\#x27;exploitation très spécifiques, tout en estimant qu&\#x27;un grand nombre d&\#x27;hôtes pourraient être concernés.
